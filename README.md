# Bridge Talk

## Description

This project is the answer to the problem for us to meet online easily, especially for people with disabilities to be able to help all of us and also them (disabled) to understand each other.

## Installation

1. Clone the repository

```bash
git clone https://github.com/Danni4421/bridge-talk-be.git
```

2. Install dependencies

```bash
pnpm install # we recommend using pnpm
```

## Usage

To start the application, you can run with this command:

```bash
pnpm start
```
